# BrightLearning

This project is an intelligent web and mobile application designed to help students organize their studies and improve learning efficiency. By integrating artificial intelligence with a modern and user-friendly interface, the system provides a personalized and adaptive learning experience.

The platform targets students of all levels who are seeking a smarter, more effective way to manage their studies and achieve academic success.

---

## Objectives

- Personalize the learning experience based on individual learning styles  
- Automate the creation of study materials such as summaries, quizzes, and flashcards  
- Improve understanding and long-term information retention  
- Provide adaptive study plans based on student performance  
- Maintain motivation and focus through positive reinforcement  

---

## System Features

- AI-powered learning style analysis (Visual, Auditory, Kinesthetic)  
- Upload support for study materials (PDFs, books, images)  
- Automatic generation of summaries, quizzes, and flashcards  
- Dynamic and adaptive study planning  
- Motivational content and Islamic reminders  
- Cross-platform accessibility (Mobile and Web)  
- Administrator dashboard for content and performance management  

---

## Technology Stack

- **Frontend (Mobile):** React Native, Expo  
- **Frontend (Web):** React.js  
- **Backend:** Node.js, Express.js  
- **Database:** MySQL  
- **AI Integration:** OpenAI API  

---

## Mobile Application

The mobile application serves as the primary interface for students and allows users to:

- Access a personalized dashboard  
- Upload study materials directly from their device  
- Interact with AI-generated summaries, quizzes, and flashcards  
- Track progress and receive adaptive study plans  
- Receive motivational quotes and reminders  

---

## Web Application & Admin Dashboard

The web application provides a full-featured experience for desktop users and includes an administrator dashboard for:

- Monitoring user activity and system performance  
- Analyzing learning data and trends  
- Managing educational content and user accounts  

---
