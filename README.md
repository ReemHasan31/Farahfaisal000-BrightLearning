# BrightLearning
This project is an AI-powered web and mobile application that helps students organize their studies and learn more efficiently. The system provides personalized learning support, generates study materials automatically, and adapts study plans based on student performance and available time.

 Features
1. Personalized Learning Experience

Learns from student behavior and study patterns

Adapts content to different learning styles

2. Automated Study Content

Upload study materials (PDFs, books, images)

Generates concise summaries

Creates quizzes and flashcards to improve retention

3. Adaptive Study Planning

Builds dynamic study schedules

Adjusts plans based on progress and availability

4. AI-Powered Assistance

Automatic summarization and question generation

Personalized study recommendations

5. Cross-Platform Applications

Mobile application built with React Native (Expo)

Web application developed using React.js

6. Administration & Analytics

Administrator dashboard for content management

User activity monitoring and performance analysis

Technology Stack

Frontend (Web): React.js

Frontend (Mobile): React Native (Expo)

Backend: Node.js, Express.js

Database: MySQL

AI Integration: OpenAI API
