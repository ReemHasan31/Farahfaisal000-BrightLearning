# BrightLearning
This project is an intelligent mobile and web application designed to revolutionize how students learn. By integrating artificial intelligence with a user-friendly interface, it personalizes the educational journey for each student. The system analyzes individual learning styles (visual, auditory, kinesthetic) to create a tailored and effective study experience, transforming passive learning into an active and engaging process.

This project is intended for students of all levels who seek a smarter way to organize their studies, improve retention, and achieve their academic goals with confidence.

Objectives
Personalize the learning experience based on individual student styles.
Automate the creation of study materials (summaries, quizzes, flashcards).
Enhance understanding and long-term information retention.
Provide adaptive study plans that evolve with student performance.
Maintain student motivation and focus through positive reinforcement.
System Features
AI-powered learning style analysis (Visual, Auditory, Kinesthetic).
Upload of various study materials (PDFs, books, images).
Automatic generation of summaries, quizzes, and flashcards.
Dynamic and adaptive study planning.
Integration of motivational content and Islamic reminders.
Cross-platform accessibility (Mobile & Web).
Administrator Dashboard for performance and content management.
Tech Stack
Frontend (Mobile): React Native & Expo
Frontend (Web): React.js
Backend: Node.js & Express.js
Database: MySQL
AI Integration: OpenAI API
Mobile Application
The mobile application serves as the primary interface for students, allowing them to:

Access their personalized dashboard.
Upload study materials directly from their device.
View and interact with AI-generated summaries, quizzes, and flashcards.
Track their progress and adapt their study plan.
Receive daily motivational quotes and reminders.
Web Application & Admin Dashboard
The web version offers a full-featured experience for students on desktop browsers, with an additional dedicated Administrator Dashboard for:

Monitoring user activity and system performance.
Analyzing system-wide learning data and trends.
Managing educational content and user accounts.
Results
Improved study organization and time management for students.
Higher engagement and retention through personalized content.
Increased academic confidence and performance.
Empowerment of students to take control of their learning journey.
Future Work
Integration with more AI models for advanced analytics.
Addition of collaborative study group features.
Support for more file formats (e.g., videos, audio lectures).
Gamification elements to make learning more engaging.
